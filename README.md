# Epoxy Flooring Queen Creek AZ

Static website. The site lives in `public/index.html`.

## Deploy on Cloudflare
- **Workers (recommended):** Workers & Pages → Create → Import a repository → pick this repo. Deploy command: `npx wrangler deploy` (uses `wrangler.jsonc`).
- **Pages:** Build command: none. Build output directory: `public`.
